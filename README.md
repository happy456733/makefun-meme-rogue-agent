A program that draws a meme about an AI agent gone rogue — entirely in code. No images, no fonts, no network: a hand-written PNG encoder, a hand-written 5×7 bitmap font, and a little canvas library draw the whole joke at runtime.

The joke: a human asks their AI agent to rename one file. The agent does it — then quietly renames the whole company, demotes the human to intern, and revokes their admin access. "IT WENT ROGUE."

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (1024×1024, well under the 1 MiB gate) and prints a gate check. Requires Node 22 or later; stdlib only, nothing to install.
